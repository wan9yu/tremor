# 地堡日报

> English handle: **tremor** · Bunker Daily —— 清晨从地面传进地堡的幸存者电台

每天一期、大部分自动化的地面读数。数字来自 tremor 张力指标仪器;**多数日子诚实地说"平静",
极少数真出事的日子平静地说清楚**。安静时诚实,那天它响才有分量——**地震仪,不是先知**。

## 两个渠道(详见 [渠道与去风险](渠道与去风险.md))

同一套数据、同一个地堡设定,两个渠道:

- **X(英文)· Bunker Daily** —— 完整原味,无域内审核约束。成品见 [`editions/bunker-daily-*.md`](editions/)。
- **微信订阅号(中文)· 地堡日报** —— **地堡牌子与电台口吻保留**,仅把三处敏感指标(人民币 / 航道 /
  断网)的**措辞**中性化。成品见 [`editions/地堡日报-*.md`](editions/)。

---

## 通用注意思想(做每一期都要守)

### 1. 诚实是命
- 多数日子答案就是"平静"——照实说,不为流量制造焦虑。
- 缺数据就说缺(dark / 滞后如实标注);不预测、不荐股、不做政治评论。
- 只描述,并标数据源(FRED、纽约联储、IODA、NOAA、IMF PortWatch、GDELT)。

### 2. 程序定调,LLM 只配音
- 所有数字与判断来自 tremor 的 `data/*.csv`——共振数、卡死状态、每条线的 z / status / 归因。
  **判断权不在 LLM 手里。**
- LLM 只把结构化读数翻译成电台口吻。硬约束写进 prompt:**只描述给定的这些数字;不得预测、
  不得添加数据里没有的事件、不得给投资建议**。这样 LLM 不会幻觉出一场不存在的危机。

### 3. 声音:非人称
- 全文**不出现"你 / 我 / 我们"**,保持仪器 / 电台播报腔。

### 4. 域内敏感点处理(中文公众号)
地堡牌子与电台口吻**保留**(末日 / 地堡的观感风险由账号主人自行承担);仅把下面三处的**措辞**
中性化,因为这三个话题才是最实打实的审核雷:

- **人民币** → 只作"境内外人民币汇率差(市场技术指标)",去掉资本管制 / 外逃框架。
- **航道(原霍尔木兹 / 刻赤海峡)** → 只作"个别主要航道通行量低于常态"(源 PortWatch),
  **不点名海峡、不归因、不点评**。
- **断网** → 纯技术化("网络可达性 / 大范围中断",源 IODA),不解读成因。
- 全程只描述、标数据源、不预测、不荐股、不做政治评论;缺数据就说缺。
- **以上是编辑性去风险,不替代平台内容审核或专业法务意见;能否过审由平台判定。涉汇率 /
  地缘的措辞,正式发布前请懂行的人再过一眼。**
