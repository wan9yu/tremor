## 每日结构(六段,自缩放)

**自缩放原则**:安静的日子每段一行("平静"),真出事的日子对应段落自动展开成头版。
②③④ 三段共同保证"安静的日子也有东西读"——缺口、卡死天数、最活跃的表,总有一个在动。

两个渠道**栏目相同**;中文版只在 ③ 段把措辞中性化(见 [渠道与去风险](渠道与去风险.md))。

## ②段的核心框架:感觉 vs 真实(四象限)

tremor 的双层设计天生产出四种格子。这是全份晨报里最独特、别处买不到的一段:

|  | 仪器平静(真的没事) | 仪器颤动(真的在裂) |
|---|---|---|
| **人心慌** | 🟡 **虚惊**——上面在恐慌,仪器说没事。*别被吓着。* | 🔴 **真事**——地面在裂,人心也在裂。 |
| **人心稳** | 🟢 **双重平静**——地面静,人也静。 | ⚠️ **先于地面**——仪器已动,地面还没反应过来。 |

**右下角那一格最关键**:张力线可以在 VIX 和新闻反应过来*之前*就动——意味着地堡先于地面上
恐慌的人群知道。这是 tremor 两层结构的真实产出,不是玄学。左上角则是纯粹的安慰剂解毒:
上面在瞎慌,仪器却是冷的。
