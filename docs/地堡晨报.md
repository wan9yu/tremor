# 地堡晨报

> English handle: **tremor** · 载体:微信订阅号 · 形态:每日一期、大部分自动化的双语地面播报

## 一句话

每天清晨从地面传进地堡的**幸存者电台**——一份诚实的地面读数,写给认真对待"崩溃"、
却已经受够了煽动的人。

## 定位

- **受众**:末日 / 地堡人群——认真对待崩溃的人。
- **反差就是卖点**:这群人被恐慌内容喂养,每个末日号天天尖叫,于是没有一个可信。
  tremor 反其道而行——它从不狼来了,所以**那天它响,你会信**。这不是软弱,是这群人
  真正想要的那块表盘:安静时诚实地说安静,极少数真出事的早晨平静地说"别上来"。
- **一句话定位**:**地震仪,不是先知**。它不预言末日,它忠实地探测。

## 声音与设定(conceit)

- **设定**:假装写给**已经在地堡里的人**。每一期都是清晨响起的地面播报。
- **语气**:黑色幽默 + 克制。电台口吻,板着脸报读数,带一丝会心的冷幽默。
- **落款仪式**:固定收束句,例如「明天同一频率。」

## 每日结构(六段,自缩放)

**自缩放原则**:安静的日子每段一行(「平静」),真出事的日子对应段落自动展开成头版。
②③④ 三段共同保证"安静的日子也有东西读"——缺口、卡死天数、最躁动的表,总有一个在动。

| # | 栏目 | 回答的幸存者问题 | 数据来源 |
|---|---|---|---|
| ① | **今天能上来吗?** | 世界真的裂了吗 | `summary.csv` 的 tier-1 共振数 N/4 + 四条主线各自 z/status |
| ② | **上面的人慌不慌?** | 人群在恐慌吗 + **缺口** | `vix` / `gdelt` / `gdelt_tone`,并判定落在四象限哪一格 |
| ③ | **地面还堵着哪些口** | 哪里长期坏着 | `stuck.csv`(level probe:卡死的海峡 + 天数,约滞后 10 天) |
| ④ | **今晨最躁动的那台表** | 什么最接近报警 | 全线中 \|z\| 最大者,讲它在防什么、为何动/未动 |
| ⑤ | **你舱里那台表** | 认识你的监测设备 | 22 条线的科普轮播,每天一条(约两个月不重样) |
| ⑥ | **签收** | —— | 电台落款 + 诚实声明 + 实时仪表盘链接 |

## ②段的核心框架:感觉 vs 真实(四象限)

tremor 的双层设计天生产出四种格子。这是全份晨报里最独特、别处买不到的一段:

|  | 仪器平静(真的没事) | 仪器颤动(真的在裂) |
|---|---|---|
| **人心慌** | 🟡 **虚惊**——上面在恐慌,仪器说没事。*别被吓着。* | 🔴 **真事**——地面在裂,人心也在裂。 |
| **人心稳** | 🟢 **双重平静**——地面静,人也静。 | ⚠️ **你先知道**——仪器已动,上面还没反应过来。 |

**右下角是地堡里的人最想要的一格**:张力线可以在 VIX 和新闻反应过来*之前*就动——
那意味着你在地堡里,比地面上恐慌的人群更早知道。这是 tremor 两层结构的真实产出,不是玄学。
左上角则是纯粹的安慰剂解毒:上面在瞎慌,你的仪器是冷的。

## 自动化分工:程序定调,LLM 配音

- **程序定调**:所有数字与判断都来自 tremor 的 `data/*.csv`——共振数、卡死状态、每条线的
  z / status / 归因(attribution note)。判断权不在 LLM 手里。
- **LLM 只配音**:把结构化读数翻译成电台口吻。**硬约束(写进 prompt)**:只描述给定的这些
  数字;**不得预测、不得添加数据里没有的事件、不得给投资建议**。这样 LLM 不会幻觉出一场不
  存在的危机——正好继承 tremor "诚实仪器"的基因。真出事那天语气可以重,但内容仍只是把数据
  和归因讲清楚。
- **发布**:微信**订阅号**(唯一允许每天群发的类型;服务号一月仅 4 次)。每天一次、固定时间。
  **大部分自动**:程序跑完 `collect.py` → 取数据 → LLM 生成草稿 → 人审 → 群发。全自动群发
  需微信认证(个体工商户主体,¥300/年)。

## 诚实与合规原则

- 只描述、标数据源(FRED、纽约联储、IODA、NOAA、IMF PortWatch、GDELT)。
- 不预测、不荐股、不做政治评论。缺数据就说缺(dark / 滞后如实标注)。
- 「地震仪不是先知」既是定位,也是最安全的合规姿态。

## 双语

中文为主;英文可选附于文末(tremor 本就是双语工程)。
