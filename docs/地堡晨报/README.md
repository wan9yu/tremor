# 地堡晨报

> English handle: **tremor** · 一台诚实的世界读数仪的每日播报

每天一期、大部分自动化的世界读数。数字来自 tremor 张力指标仪器;**多数日子诚实地说"平静",
极少数真出事的日子平静地说清楚**。安静时诚实,那天它响才有分量——**地震仪,不是先知**。

## 两个渠道(详见 [渠道与去风险](渠道与去风险.md))

- **X(英文)· Bunker Morning Post** —— 保留"地堡 / 末日电台"原味。海外渠道,无域内审核约束。
- **微信订阅号(中文)· 今日世界读数(工作名)** —— 域内去风险版:中性名 + 平和口吻 + 敏感指标中性化。

当日成品按日期放在 [`editions/`](editions/)。

---

## 通用注意思想(做每一期都要守)

### 1. 诚实是命
- 多数日子答案就是"平静"——照实说,不为流量制造焦虑。
- 缺数据就说缺(dark / 滞后如实标注);不预测、不荐股、不做政治评论。
- 只描述,并标数据源(FRED、纽约联储、IODA、NOAA、IMF PortWatch、GDELT)。

### 2. 程序定调,LLM 只配音
- 所有数字与判断来自 tremor 的 `data/*.csv`——共振数、卡死状态、每条线的 z / status / 归因。
  **判断权不在 LLM 手里。**
- LLM 只把结构化读数翻译成口吻。硬约束写进 prompt:**只描述给定的这些数字;不得预测、不得
  添加数据里没有的事件、不得给投资建议**。这样 LLM 不会幻觉出一场不存在的危机。

### 3. 声音:非人称
- 全文**不出现"你 / 我 / 我们"**,保持仪器 / 播报腔。

### 4. 域内合规红线(中文公众号)
- 不用"末日 / 地堡 / 能上来吗 / 别上来"等设定与警报观感;改中性名 + 平和口吻。
- 人民币线只作"境内外人民币汇率差(市场技术指标)",去掉资本管制 / 外逃框架。
- 航道线只作"个别主要航道通行量低于常态"(源 PortWatch),**不点名海峡、不归因、不点评**。
- 断网线纯技术化("网络可达性 / 大范围中断",源 IODA),不解读成因。
- **以上是编辑性去风险,不替代平台内容审核或专业法务意见;能否过审由平台判定。涉汇率 /
  地缘的措辞,正式发布前请懂行的人再过一眼。**
