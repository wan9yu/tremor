## 域内去风险对照

把明显敏感点降下来的编辑性处理:

| 原(英文 / X 版) | 域内改动 | 原因 |
|---|---|---|
| 地堡 / 末日 / "能上来吗"设定 | 去掉,改中性名 + 平和仪器口吻 | 避免"渲染末日焦虑" |
| 离岸-在岸人民币价差 · 资本管制框架 | 改"境内外人民币汇率差(市场技术指标)",去因果 | 涉汇率 / 资本流动敏感 |
